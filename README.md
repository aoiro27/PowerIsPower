# Power Is Power

iPhone向けのシンプルな筋トレサイクル管理アプリ。SwiftUI製、iOS 17以降に対応しています。

## 使い方

- 「トレーニング」に次回のサイクルと種目・重量・回数を表示します。
- 「サイクル」で1日分のメニューを作成・編集・削除・並べ替えできます。次に行うサイクルを手動で指定することもできます。
- 各種目に重量、追加重量、回数を登録します。例：シーテッドロー 80kg、追加2.5kg、10回。
- 種目ごとにkg／LBSを選んで入力できます。単位の切り替え時は重量と追加重量を換算し、メニュー・完了確認・履歴に両方の単位を表示します（1 LBS ≈ 0.45 kgの近似計算）。換算表示は小数点以下を切り捨てた整数で、保存・増量の計算には丸め前の値を使います。入力した値の小数は維持します。既存データはkgとして引き継ぎます。
- 完了時に「次回の重量を増やす」を選ぶと、このサイクルの重量が追加重量分増えます。例：次に同じサイクルを行うときは82.5kg。オフにすると重量を維持します。
- 完了後は次のサイクルへ進み、最後まで進むと最初へ戻ります。
- 「履歴」には実施時点のメニューを保存します。メニューを編集・削除しても過去の記録は変わりません。

初回は例の2種目が入ったサイクル1を表示します。サイクル2以降は好きなメニューを追加してください。
データは端末内のApplication SupportにJSONで保存します。アカウントや通信は不要です。クラウド同期はありません。アプリを削除すると保存データも削除されます。

## 起動

1. `PowerIsPower.xcodeproj`をXcodeで開きます。
2. `PowerIsPower`スキームとiPhoneシミュレータを選び、Runします。
3. 実機ではSigning & Capabilitiesで自分のDevelopment Teamを設定します。必要に応じてBundle Identifierも変更してください。

プロジェクト定義を変更した場合は、XcodeGenをインストールした環境で`xcodegen generate`を実行します。
テストはXcodeのProduct > Test（⌘U）で実行できます。
